## DESCRIPCIÓN DEL PROYECTO

Este proyecto consiste en el desarrollo de un **portfolio web personal**, creado utilizando HTML5, CSS3 y Sass (SCSS).

Su finalidad es poner en práctica los conocimientos adquiridos en desarrollo frontend, prestando especial atención a la estructura semántica del documento, la organización de los estilos y la creación de interfaces visuales modernas.

El proyecto también representa una oportunidad para profundizar en buenas prácticas de desarrollo web, mejorar la mantenibilidad del código y consolidar habilidades de maquetación.

## DISEÑO Y MAQUETACIÓN

El desarrollo del portfolio se centra en combinar una estructura HTML semántica con estilos CSS organizados mediante Sass.

### HTML5

Utilizado para definir el contenido de la página y establecer una jerarquía adecuada mediante elementos semánticos.

### CSS3

Responsable del diseño visual, la tipografía, los colores, los espaciados y la distribución de los elementos.

### Sass (SCSS)

Empleado como preprocesador CSS para facilitar la organización de los estilos y permitir una arquitectura más escalable mediante funcionalidades como variables, anidamiento y separación de archivos.

### Diseño responsive

El proyecto contempla la adaptación de la interfaz a distintos dispositivos mediante técnicas de diseño flexible y consultas de medios (*media queries*).

## INSTALACIÓN Y EJECUCIÓN

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### 2. Acceder al proyecto

```bash
cd portfolio-web
```

### 3. Visualizar la página

Abrir el archivo `index.html` en un navegador web o utilizar la extensión **Live Server** de Visual Studio Code.

### 4. Compilar Sass

Si se dispone de Sass instalado y se utiliza la estructura indicada:

```bash
sass scss/style.scss css/style.css --watch
```

Este comando permite observar los cambios realizados en el archivo SCSS y compilarlos automáticamente a CSS.
